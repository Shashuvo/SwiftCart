1) What is the difference between null and undefined?
Answer: null: It is a value assigned intentionally by the programmer
        undefined: A variable declared but not assigned any value. It is default by JS.

2) What is the use of the map() function in JavaScript? How is it different from forEach()?
Answer: map(): creates a new array of elements.
        forEach(): executes all value but does not return new array.

3) What is the difference between == and ===?
Answer: ==: inly checks the value, does not check the typeOf value.
        ===: checks both value and typeOf value.

4) What is the significance of async/await in fetching API data?
Answer: It makes code synchronous and easy to read. It also handle promises without .then()

5) Explain the concept of Scope in JavaScript (Global, Function, Block).
Answer: Global Scope: Accessible anywhere in the code.
        Function Scope: variables declared in the function Accessible only in the function.
        Block Scope: variables declared with let or const inside {} are accessible only within that block.
